# Auditoría técnica SEO — 14/10/2026

## Cambios realizados

- Normalización del HTML: título, charset y viewport dentro del head, con charset al principio. Se eliminaron marcas BOM internas que podían cerrar prematuramente el head durante el parseo.
- El generador SEO elimina esas marcas antes de analizar el HTML para prevenir la regresión.
- Título español del curso de branding diferenciado del inglés, sincronizado entre HTML, metadatos sociales, configuración en página y catálogo del generador.
- Auditoría estática reproducible, sin dependencias de Node, en `scripts/audit-seo.ps1`.

## Resultado verificado

Ambas carpetas del sitio pasan la auditoría: 55 páginas indexables, 55 URLs únicas en sitemap y cero errores detectados por el script.

Comprobaciones: título, descripción y canonical únicos; un H1 por página; charset, viewport y título en head; JSON-LD parseable; concordancia con el catálogo SEO; variantes hreflang esperadas en ambas versiones; existencia de destinos internos y recursos HTML referenciados; correspondencia entre canonical y sitemap. Se incluyen las páginas noindex al revisar recursos.

## Alcance y límites

Es una revisión estática del código local. No demuestra indexación, posiciones, tráfico, estado HTTP del alojamiento, renderizado en móviles ni Core Web Vitals. No se ejecutaron los checks de Playwright porque Node no está disponible en este entorno. No hubo acceso a una propiedad autenticada de Search Console. No se modificaron el diseño ni los textos comerciales del cuerpo de las páginas.

## Ejecutar

Desde la carpeta del sitio:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/audit-seo.ps1
```

Cuando Node y las dependencias estén disponibles, complementar con `npm run check:seo` y `npm run check:paths` para validar renderizado y navegación.
